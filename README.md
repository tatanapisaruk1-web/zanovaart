# ЗАНОВО — админ-панель

Внутренняя админ-панель Арт-студии ЗАНОВО. Next.js + Supabase (Postgres) + Vercel.

Полный план разработки и концепция — в проекте claude.ai «Арт-студия ЗАНОВО»,
документ `plan-admin-panel.md`.

## Стек

- **Next.js 14** (App Router, TypeScript) — фронтенд и бэкенд в одном приложении
- **Supabase** — база данных Postgres, авторизация, файловое хранилище
- **Tailwind CSS** — стили
- **Vercel** — хостинг и автодеплой

## Структура

```
src/app/                    страницы (App Router)
supabase/migrations/        SQL-миграции схемы БД
```

## Локальный запуск

```bash
npm install
cp .env.example .env.local   # заполнить ключами из своего проекта Supabase
npm run dev
```

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | URL проекта Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | публичный (anon) ключ Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | сервисный ключ (только на сервере, для серверных операций) |

## Этапы разработки

0. Фундамент — репозиторий, Supabase, Vercel, вход по логину
1. MVP-ядро — мастер-классы, слоты (включая мультитиповые), брони, дашборд
2. Склад — остатки, поставки, автосписания, прогноз закупки, инвентаризация
3. Сертификаты, Финансы и Ведущие
4. Роли доступа
5. Telegram-мини-апп для мастеров
6. Полировка

Подробности — в плановом документе проекта.
